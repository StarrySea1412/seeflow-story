一个会看画面的 agent，由六层组成。越往上越接近模型（会产生断言），越往下越接近证据（必须可回查）。这张图不是库清单，是「每条结论的证据从哪来、错在哪一层被拦住」。每一格都在回答同一个问题：这里凭什么说的算？

LAYERSUBSYSTEMS ／ 每一格 = 一道可回查的环节
L5模型层

文本模型

MAP / REDUCE

分段归并 + 全局摘要。时间戳只许引用输入，不生成。

视觉模型

VLM

多帧 + 当时字幕/OCR 一起看；输出 note / quoted_text / confidence。

视觉真伪探测

RANDOM PROBE

随机方块题面，盲猜 <2%。答不对就别号称有视觉。

GATE

审核员

REVIEWER

全新上下文；只杀「直接矛盾」与「编造实体」，材料不足标 insufficient。

L4证据层

统一时间轴

TIMELINE

每条 = 字幕 + OCR + 视觉笔记 + 帧。全系统的唯一真相源。

CORE

证据绑定

EVIDENCE BIND

visual.evidence 为空 → 构造即抛异常，不是提示词约束。

注意力预算

ATTENTION

指代 +2 / 切点 +1 / 弹幕 0–2；贪心 + 最小间隔。

补帧规划

BACKFILL

按时间分桶 + 视觉线索打分；≤12 帧，只认 ffmpeg pts。

L3校验层

时间戳贴回

SNAP

±1s（map）/ ±15s（reduce）；贴不回就是编造，直接丢。

FREE

bigram 回查

VERIFY

±20s 窗口命中率 ≥0.22；keep / repair / drop 三值。

OCR 交叉

CROSS-CHECK

quoted_text 必须在同帧 OCR 里；否则 unconfirmed，不作事实。

金句逐字

QUOTE LOCK

连续字幕逐字 + 词边界；找不到原话就不给引号。

L2管线层

150 秒分段

CHUNK

map 并行 4 worker，失败隔离；连续失败 5 段触发渠道熔断。

分层压缩

CONDENSE

>360 条 → 120/批 → 留 12；细节换可读性。

缓存身份

CACHE KEY

内容 + prompt + 后端身份 + ASR 不确定标注；换条件必失效。

覆盖账本

COVERAGE

请求/完成/失败逐段记账；缺口写进 reduce 提示词。

L1降级层

四档阶梯

LADDER

云 VLM → 本地 VLM → 信号 → 纯字幕；档位写进报告。

首字节竞速

RACING

2 候选并发取首个可解析 JSON，胜者即返；常规调用顺序 failover，同站只留一个候选。

站点熔断

BREAKER

连续 2 次失败冷却 120s；半开探针。跨任务记忆。

降级报告

DEGRADED

全队列挂掉也交时间轴 + 帧；重跑走缓存 30 秒补全。

L0底座层

确定性媒体

FFMPEG

只读不重编码；-ss 精确截帧，时间轴基准永不动。

文字轨

SUBTITLE / ASR

平台字幕优先，faster-whisper 兜底；词级时间戳 + 不确定标注。

评测靶场

EVAL

19 条金标准 + 4 条视觉点；双重判定 + 幻觉率 + 视觉增益。

质量门

QUALITY GATE

只体检不判决；pass / review / fail，从不删内容。

TRUTH

WHY THIS SHAPE

上面两层负责「看见」，中间两层负责「站得住」，下面两层负责「不熄火」。所有视觉幻觉都发生在「模型说了什么」和「有什么可回查」之间的缝隙里——所以每一格都配了一条确定性检查或一个诚实的状态。

3587 个测试里，真正调用模型的不到一成；其余都在测这些「缝隙」：贴回、命中率、边界、覆盖、缓存身份。

THE ARITHMETIC

命中率 hit = |g₁∩g₂| / |g₁| ≥ 0.22
评测更严：≥ 0.25 且 Δt ≤ 15s
视觉增益 = 视觉点命中 / 4
